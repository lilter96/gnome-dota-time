# Dota Time

[![test](https://github.com/lilter96/gnome-dota-time/actions/workflows/test.yml/badge.svg)](https://github.com/lilter96/gnome-dota-time/actions/workflows/test.yml)

Расширение GNOME Shell: сколько ты сегодня в Dota 2. Время видно в верхней панели.
Рядом живёт Рошан: он спит, пока Дота закрыта, просыпается, когда она запускается,
ворчит ближе к вечеру и после четырёх часов впадает в агр. В попапе есть матчи дня
с героями, графики за день, неделю и месяц и честные сравнения.

## Что считается временем в Доте

**Матч считается всегда, остальное только когда Дота перед глазами.** Пока идёт матч,
время идёт, даже если ты свернул игру в ожидании воскрешения. Вне матча, то есть в меню
и в поиске, время идёт, только пока окно Доты в фокусе. Если Дота висит в фоне, а ты
сидишь в браузере, время стоит. Пробный герой, тренировка и аркада не считаются вовсе.
Если десять минут нет ни клавиатуры, ни мыши и ты не в матче, эти десять минут
вычитаются задним числом. Пока экран заблокирован, расширение выключено, поэтому это
время тоже не идёт. Почему время стоит, видно в попапе: «Дота в фоне, время стоит».

**День начинается в 05:00.** Катка в два ночи относится к вечеру, с которого всё
началось, а не к новому дню.

**Живые матчи через Game State Integration.** Это официальный канал Valve, через
который Дота сама сообщает о матче. Расширение кладёт файл
`gamestate_integration_dota_time.cfg` в `game/dota/cfg/gamestate_integration/`
и слушает `127.0.0.1:47570` со случайным токеном. Сообщения без этого токена
отбрасываются. Отсюда берутся герой, игровое время, K/D/A и исход матча, а Рошан
радуется победе и расстраивается из-за поражения. С 2022 года Дота шлёт эти данные
только с параметром запуска
[`-gamestateintegration`](https://liquipedia.net/dota2/Launch_Options). Добавь его в
Steam → Dota 2 → Свойства → Параметры запуска. Расширение проверяет параметр в командной
строке Доты. Пока его там нет, в попапе есть кнопка, которая копирует параметр. До первой
игры Дота молчит: первое сообщение приходит, когда грузится карта. Пробный герой,
тренировка и аркада показываются голубой строкой и в матчи не попадают.

**История из OpenDota.** Аккаунт берётся из `loginusers.vdf` Steam: последний, кто
входил. Расширение подтягивает матчи за 60 дней, чтобы графики не были пустыми с первого
дня, и обновляет последние 20 матчей после игры. Дни до установки известны только по
длительности матчей. Поиск, драфт и меню в них не попали, поэтому это нижняя граница.
Такие столбики на графике бледнее. Чтобы OpenDota видела матчи, в настройках Доты должна
быть включена опция Expose Public Match Data.

## Сравнения

Сравнивается только одинаковое с одинаковым. День, который расширение видело целиком,
включает меню и поиск. День из OpenDota знает только игровое время матчей. Если
поставить их рядом, любой новый день выглядел бы длиннее старых. Поэтому, пока по
одну сторону сравнения есть дни только по матчам, обе стороны считаются по времени
в матчах, и плитка так и подписана: «День в матчах», «Неделя в матчах». Когда целиком
увиденных дней становится достаточно, плитки переходят на полное время. Отсчёт идёт
со следующего дня после установки: сегодняшний день начался раньше расширения.

| Плитка | Как считается |
|---|---|
| **К обычному дню** | Сегодня против медианы последних 28 игровых дней. Полное время сравнивается, когда есть три целиком увиденных игровых дня. До этого сравнивается время в матчах. |
| **Неделя к прошлой** | Семь дней против семи предыдущих. Полное время сравнивается, если прошлая неделя целиком увидена. Иначе с обеих сторон время в матчах. |
| **Дни в агре** | Дни от четырёх часов за неделю и за месяц, плюс сколько дней подряд обошлось без агра. Если в периоде есть дни только по матчам, счёт помечен как минимум: такой день мог быть длиннее. «Спокойные» дни считаются только среди увиденных целиком. |
| **Винрейт за день** | Первые три игры дня против остальных, без подгонки чисел. Разница проверяется точным тестом Фишера. Если p ≥ 0,05, плитка пишет «разницы нет» и не красит цифры: такой разрыв часто даёт случайность. Плитка появляется, когда в каждой группе есть хотя бы 8 игр, а до этого показывает матчи за неделю. |

На недельном графике за столбиками стоят серые тени прошлой недели. Если день прошлой
недели известен только по матчам, а сегодняшний увиден целиком, тень не рисуется,
потому что сравнение было бы нечестным.

## Игре не мешает

- **Панель не двигается.** Пока Дота на весь экран и в фокусе, панель не анимируется.
  Значок просто встаёт в новое состояние.
- **Уведомление не всплывает поверх игры.** О четырёх часах оно приходит один раз за
  день и с обычной важностью. GNOME не показывает такой баннер поверх полноэкранного окна,
  поэтому оно ждёт в списке уведомлений.
- **Фокус никуда не уходит.** Это важно: Дота с `snd_mute_losefocus 1` глохнет, как только
  теряет фокус.

## Установка

Нужен GNOME Shell 46.

```sh
git clone https://github.com/lilter96/gnome-dota-time
ln -s "$PWD/gnome-dota-time/dota-time@terentiy" ~/.local/share/gnome-shell/extensions/
gnome-extensions enable dota-time@terentiy
```

Затем перезапусти Shell: на X11 это Alt+F2 → `r`, на Wayland нужно перелогиниться.
После этого добавь `-gamestateintegration` в параметры запуска Доты.

## Данные

- **Где лежит:** состояние в `~/.local/state/dota-time/state.json`, портреты героев с CDN
  Steam в `~/.cache/dota-time/heroes/`.
- **Куда ходит сеть:** только `api.opendota.com` и `cdn.cloudflare.steamstatic.com`.
- **Ключи:** не нужны.
- **Первая версия:** если рядом найдётся её `history.json`, он импортируется один раз.

## Разработка

```sh
gjs -m tests/run.js                  # учёт времени, GSI, Рошан
gjs -m tools/frames.js out.png 2     # Рошан во всех состояниях, без перезапуска Shell
gjs -m tools/glyph.js out.png        # значок панели крупно
tools/media/capture.sh smoke         # настоящий Steam-аккаунт, OpenDota и пост GSI в изолированном Shell
tools/media/capture.sh media         # медиа для README на выдуманных данных
```

Обе капчи запускают одноразовый `gnome-shell --headless` с отдельными шиной, dconf,
XDG-папками и даже `$HOME`, где лежит поддельный Steam. Поэтому тестовый конфиг GSI не
попадает в настоящую Доту. Режим `--mode=user` выбран намеренно: Ubuntu-режим грузит
Desktop Icons NG, а его `init()` убивает процесс рабочего стола в твоей настоящей сессии.

Родственник [gnome-headphones-battery](https://github.com/lilter96/gnome-headphones-battery):
та же пружинная анимация и тот же подход к персонажу.
